Parallax Launcher

A desktop application that collects the games installed on your computer into a single library, adds their cover art and starts them. It reads Steam's own installation records, and all of its data is stored on your machine.

Features

How Parallax finds your games

Parallax reads the installation records Steam keeps on disk rather than searching folders, so the library reflects what is actually installed.

Detection

Installed games

Steam library folders and installation manifests are read directly, across every drive, including the correct title and application id for each game.

Launching

Starting a game

A game can be started through Steam or run directly, so that the Steam window does not open. The method is set per game, and the exact command to be run is shown before it runs.

Artwork

Cover images

Cover images and banners for Steam games are downloaded from Steam and require no account or API key. Adding a SteamGridDB key extends this to games sold elsewhere.

Play time

Recorded hours

Parallax records the sessions it starts and merges them with the play time Steam recorded previously. The higher value is used, so existing records are never reduced.

Compatibility

Proton and Wine

Runtime selection per game, launch options using Steam's %command% syntax, environment variables, GameMode and MangoHud.

Data

Local storage

The library is a plain text file and the images are ordinary image files. Nothing is uploaded and no account is required.

Compatibility

Compatibility settings

Each game has its own runtime settings. The command that will be used to start the game is shown as the settings are changed.

Languages

Available in eight languages

The interface is fully translated into English, Turkish, German, Russian, Ukrainian, Portuguese, Simplified Chinese and Korean.

Removing Parallax

Your library, settings and artwork are stored in ~/.config/parallax-launcher on Linux and %APPDATA%\parallax-launcher on Windows. None of the steps below affect that folder, so reinstalling continues from the same state. Delete it manually if you want everything removed.

.AppImage

Delete the file. The menu entry and icon it created remain and can be removed with: 

rm ~/.local/share/applications/parallax-launcher.desktop
rm ~/.local/share/icons/hicolor/256x256/apps/parallax-launcher.png
rm -r ~/.cache/parallax-launcher-updater
.deb

Remove it as you would any other package. If you added the repository, remove that as well: 

sudo apt remove parallax-launcher
sudo rm /etc/apt/sources.list.d/parallax.list
Windows

Open Settings, then Apps, select Parallax Launcher and choose Uninstall.

On Debian and Ubuntu you can add the package repository instead and let your system manage updates. The commands are listed in the guides.
