Compatibility defaults

Used for every game that has not been given its own settings.

Runs the game's own file instead of asking Steam to, so Steam's window never comes to the front — and playtime gets counted here. Steam still has to be running in the background. If a game will not start this way, set it back to Automatic in that game's Properties.

Library sync

Reads Steam's own install records to find which games are really installed, and links each one to its Steam ID so it can be started.

Your API keys

Both are optional, and nothing is bundled with the app. Without them the launcher still finds your installed games and still fills every cover from Steam's public artwork.

STEAM WEB API

Lets the launcher import your whole Steam library, including games you have not installed. One-time — after the import it is never needed again. Get one at steamcommunity.com/dev/apikey

STEAMGRIDDB

Unlocks community artwork — often hundreds of alternatives per game, instead of Steam's single official cover. Get one at steamgriddb.com/profile/api

Artwork

Downloads the official cover and banner for every Steam game that has none. Free, no API key, no quota. To swap one for something more interesting, open that game and use Change Artwork.
